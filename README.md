# Elorrioko Tabloia

Directorio de todas las actividades de Elorrio: clases particulares, academias,
clubes, escuelas municipales y elkarteak. Bilingüe (euskera / castellano).

**Demostración.** Las fichas, las personas, los teléfonos, los precios y las
valoraciones son inventados. Las fotografías de las actividades son de archivo,
con licencia libre (Wikimedia Commons y Openverse), y no corresponden a las
actividades ni a las personas que aparecen en las fichas.

Web estática, sin dependencias: `index.html` y la carpeta `fotos/`.
